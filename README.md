# \# 🛒 Supermarket Data Analysis — SQL Project

# 

# \## About

# End-to-end data analysis of a supermarket system built with MySQL.

# Covers real business questions on sales, inventory, customers and employees.

# 

# \## Database Structure

# \- 9 tables: products, categories, suppliers, warehouse\_stock,

# &#x20; stock\_movements, customers, employees, orders, order\_items

# \- 100 products | 500 stock movements | 50 customers | 80 orders

# 

# \## Skills Demonstrated

# \- Complex JOINs (2 and 3 tables)

# \- GROUP BY + Aggregations (SUM, COUNT, AVG)

# \- CTEs (Common Table Expressions)

# \- Window Functions (RANK, ROW\_NUMBER)

# \- Date Functions (DATEDIFF, MONTHNAME)

# \- CASE WHEN + Pivoting

# \- Subqueries

# 

# \## Business Questions Answered

# \- Monthly sales revenue report

# \- Top customers by spending

# \- Products needing reorder

# \- Stock value by category (HIGH/LOW)

# \- Employee performance analysis

# \- IN vs OUT stock movement trends

# 

# \## Tools Used

# \- MySQL 8.0

# \- MySQL Workbench
